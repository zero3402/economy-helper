# economy-helper

재테크에 필요한 값(환율·주식·코인·뉴스·날씨)을 **매일 아침 텔레그램으로 밀어 주고, 물으면 답하는** 봇.

무료 API 여러 곳에서 값을 모은다. 출처 하나가 죽어도 답이 나가도록 도메인마다 **이중화**를 걸고,
값이 어디서 왔고 언제 것인지를 **화면이 스스로 밝힌다.** 모르는 값은 지어내지 않고 줄을 안 적는다.

```
증시                     ← 제목: 명령이 곧 제목이다

국내                     ← 무리: 지역으로 가른다

삼성전자                  ← 값: 한 종목이 블록 하나
70,700 KRW
🔵 -1.26%

한국투자증권              ← 출처: 폴백이 일어나면 여기가 바뀐다
2026년 8월 19일(수) 17:04:13   ← 기준: 실시간이면 시각, 종가면 날짜+(종가)
```

## 기능

| 명령 | 답 |
|---|---|
| `/fx` (`/f`) | 원/달러 환율 |
| `/stock {검색어}` (`/s`) | 주가·지수·국내 ETF와 목표주가·실적발표일·배당 — `삼성전자` · `삼전` · `005930` · `애플` · `코스피` |
| `/crypto {검색어}` (`/c`) | 코인 시세 — 업비트·바이낸스와 김치 프리미엄 |
| `/news {검색어}` (`/n`) | 관련 기사 상위 5건, 한글 번역. **검색어를 빼면** 코인 5 + 경제 5 |
| `/weather {검색어}` (`/w`) | 전 세계 일일 예보 — `내일 성남` · `일주일치 파리` · `다음 주 화요일 서울` |
| `/help` (`/h`) | 명령 목록 |

**정기 발송** — 오전 9시 아침 브리핑(환율·증시·코인 각 한 통 + 뉴스 열 통), 오전 8시 날씨 알람(네 지역).
환율·증시·코인 답에는 최근 14 거래일 차트가 사진으로 붙는다.

검색어는 자연어로 받는다. 약칭과 군더더기는 LLM이 풀지만 **실재 여부와 좌표는 LLM에게 맡기지 않는다** —
시세 API·종목 색인·지오코딩이 확정한다.

## 빠른 시작

**필요한 것**: JDK 21 · Docker · API 키(하나도 없어도 앱은 뜬다 — 빈 키는 그 출처만 실패시킨다)

```bash
docker compose up -d redis                       # Redis만 컨테이너로
cp backend/.env.example backend/.env             # 시크릿 — 출처마다 「없으면 무엇이 나빠지는지」 적혀 있다
cd backend && ./gradlew test                     # 무엇을 고치든 여기가 먼저다
set -a; . ./.env; set +a; ./gradlew bootRun      # .env를 셸에 풀어서 넘긴다(앱이 파일을 읽지는 않는다)
```

포트는 둘이다 — `8080` 텔레그램 웹훅, `8081` 액추에이터. 배포와 웹훅 등록은 [docs/runbook.md](docs/runbook.md).

## 구성

Spring Boot 4 (JDK 21 · 가상 스레드) · Redis(캐시·락·발송이력·토큰·쿼터) · Docker 이미지(GHCR) · Render · GitHub Actions.
`backend/`는 헥사고날 구조(컨텍스트 × 층)이고 경계는 ArchUnit이 지킨다. 프론트엔드(Vue)·애드센스·k8s는 아직 없다.
