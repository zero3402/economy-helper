# economy-helper

재테크에 필요한 값을 **매일 아침 텔레그램으로 밀어 주고, 물으면 답하는** 봇.

환율·주식·코인·뉴스·날씨를 무료 API 열 곳에서 모은다. 출처가 하나 죽어도 답이 나가도록
도메인마다 **이중화**를 걸고, 값이 어디서 왔고 언제 것인지를 **화면이 스스로 밝힌다.**

```
증시                     ← 제목: 명령이 곧 제목이다

국내                     ← 무리: 지역으로 가른다

삼성전자                  ← 값: 한 종목이 블록 하나
70,700 KRW
🔵 -1.26%

한국투자증권              ← 출처: 폴백이 일어나면 여기가 바뀐다
                          (숨기면 고장이 아니라 거짓말이 된다)
2026년 8월 19일(수) 17:04:13   ← 기준: 실시간이면 시각, 종가면 날짜+(종가)
```

---

## 기능

| 명령 | 답 |
|---|---|
| `/fx` | 원/달러 환율 |
| `/stock {검색어}` | 주가·지수 — `삼성전자` · `삼전` · `005930` · `애플` · `코스피` 다 받는다 |
| `/crypto {검색어}` | 코인 시세 — 업비트·바이낸스 두 거래소와 김치프리미엄 |
| `/news {검색어}` | 관련 기사 상위 3건, 한글 요약 |
| `/weather {검색어}` | 전 세계 일일 예보 — `내일 성남` · `일주일치 파리` · `지난주 서울` |
| `/help` | 명령 목록 |

**정기 발송** — 오전 9시 아침 브리핑(환율·증시·코인·뉴스 네 통), 오전 6시 날씨 알람(네 지역).

검색어는 자연어로 받는다. 약칭(`삼전`)과 군더더기(`오늘 삼성전자 주가`)는 LLM이 풀지만,
**실재 여부와 좌표는 LLM에게 맡기지 않는다** — 시세 API와 지오코딩이 확정한다.

## 빠른 시작

**필요한 것**: JDK 21 · Docker · API 키(하나도 없어도 앱은 뜬다 — 빈 키는 그 출처만 실패시킨다)

```bash
# 1. Redis만 컨테이너로
docker compose up -d redis

# 2. 시크릿 — .env는 gitignore 대상이다
cp backend/.env.example backend/.env    # 출처마다 "없으면 무엇이 나빠지는지" 적혀 있다

# 3. 테스트 — 무엇을 고치든 여기가 먼저다
cd backend && ./gradlew test

# 4. 실행 — .env를 셸에 풀어서 넘긴다 (앱이 파일을 읽지는 않는다)
set -a; . ./.env; set +a; ./gradlew bootRun
```

포트를 둘 연다. `8080`이 텔레그램 웹훅, `8081`이 액추에이터다.

```bash
# 스케줄을 기다리지 않고 지금 한 번 보내기
curl -X POST localhost:8081/actuator/digest -H 'Content-Type: application/json' -d '{"force":true}'

# "왜 안 왔지"는 발송 없이 먼저 이걸로 본다
curl localhost:8081/actuator/digest
```

> ⚠️ `force`를 습관처럼 쓰지 않는다. 이미 보낸 슬롯을 다시 보내는 것이라 구독자에게 중복이 간다.

## 구조

```
backend/src/main/java/io/saiden/economyhelper/
  market/     환율·증시·코인·날씨 — 출처별 클라이언트 + 이중화 서비스
  news/       수집·랭킹
  llm/        Gemini 전송 계층 + JSON 해석 골격
  translate/  번역
  telegram/   명령 파싱 · 통 조립 · 발송
  digest/     정기 발송 잡 + 슬롯
  config/     캐시·회복탄력성·스케줄·동시성
  support/    Failover(이중화 기계) · Concurrently(가상 스레드 팬아웃)
```

**벤더 이름은 패키지 이름에만 산다**(`market/kis`, `market/fmp`, `market/weather/accu`).
위층은 SPI만 안다 — 벤더를 갈아 끼울 때 고칠 곳이 그 패키지와 순서 목록 한 줄로 끝난다.

## 테스트

**488개 · 전부 통과.** 규칙이 넷 있다(자세히는 `ARCHITECTURE.md` 6절).

1. 주장 하나에 테스트 하나. `@DisplayName`에 *무엇을 주장하는지와 왜인지*를 함께 쓴다.
2. **외부 API는 실호출로 계약을 확정하고, 그 응답을 줄여 스텁 본문으로 쓴다.** 문서가 아니라
   실물이 근거다.
3. 스프링을 띄우지 않는다. WireMock + `new`로 만든다.
4. 못 지나가는 테스트는 지운다.

**화면은 `golden/messages.txt`가 지킨다.** `RenderedOutputTest`가 57가지를 렌더해 대조하므로,
구조를 옮기는 커밋에서 그 diff가 비어 있으면 화면을 안 건드렸다는 증명이 된다.

```bash
./gradlew test                                    # 전부
./gradlew test --tests '*RenderedOutputTest*'     # 화면만
```

> 단위 테스트가 전부 초록인 채로 살아 있는 버그가 있다 — 조각은 맞는데 조합이 틀린 것들이라
> 픽스처로는 안 잡힌다. **실제 키로 실제 입력을 돌려 보는 감사**가 따로 필요하고, 그 방식과
> 지금까지 그것으로 찾은 것들이 `ARCHITECTURE.md` 6·7절에 적혀 있다.

## 지금 안 되는 것

- **미국 종목의 2순위가 실질적으로 없다.** FMP 무료 티어가 심볼별 임의 허용목록이라
  `ORCL`·`SNOW` 같은 초대형주도 402다. 1순위(KIS)가 죽으면 미국 종목이 통째로 빠진다 —
  이중화가 이름만 있는 자리다. 메꾸려면 무료 티어를 하나 더 세워야 한다.
- **프론트엔드·애드센스·k8s** — `CLAUDE.md` 0-1·0-2가 적어 둔 것은 미구현이고 HTTP 진입점은
  웹훅 하나뿐이다. 다만 `NewsFacade`가 "수집·랭킹의 단일 진입점"으로 이미 갈라져 있어
  컨트롤러만 얹으면 된다 — 텔레그램과 프론트가 다른 결과를 내지 않으려면 로직이 한 군데에
  있어야 한다는 것이 그 클래스가 있는 이유다.
