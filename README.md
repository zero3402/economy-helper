# economy-helper

재테크에 필요한 값(환율·주식·코인·뉴스·날씨)을 **매일 아침 텔레그램으로 보내 주고, 물으면 답하는** 봇.

- 여러 무료 API에서 값을 모은다. 출처 하나가 죽어도 답이 나가도록 분야마다 **예비 출처**를 둔다.
- 값이 **어디서 왔고 언제 것인지** 화면에 함께 적는다.
- 모르는 값은 지어내지 않는다. 그 줄을 아예 적지 않는다.

## 이렇게 생긴 답이 온다

```
증시                              ← 제목: 명령 이름

국내                              ← 카테고리: 지역별

삼성전자                           ← 값: 종목 하나가 블록 하나
70,700 KRW
🔵 -1.26%

한국투자증권                       ← 출처: 예비 출처로 넘어가면 여기가 바뀐다
2026년 8월 19일(수) 17:04:13      ← 기준: 실시간이면 시각, 종가면 날짜 + (종가)
```

## 기능

| 명령 (줄임) | 답 | 예 |
|---|---|---|
| `/fx` (`/f`) | 원/달러 환율 | |
| `/stock {검색어}` (`/s`) | 주가·지수·국내 ETF + 목표주가·실적발표일·배당 | `삼성전자` · `삼전` · `005930` · `애플` · `코스피` |
| `/crypto {검색어}` (`/c`) | 업비트·바이낸스 시세와 김치 프리미엄 | `비트코인` · `이더` |
| `/news {검색어}` (`/n`) | 관련 기사 상위 5건, 한글 번역. **검색어 없이** 치면 코인 5 + 경제 5 | `엔비디아` · `금리` |
| `/weather {검색어}` (`/w`) | 전 세계 일일 예보 | `내일 성남` · `일주일치 파리` · `다음 주 화요일 서울` |
| `/help` (`/h`) | 명령 목록 | |

**정기 발송**

| 시각 | 내용 |
|---|---|
| 오전 8시 | 날씨 알람 (네 지역) |
| 오전 9시 | 아침 브리핑 — 환율·증시·코인 각 한 통 + 뉴스 열 통 |

- 환율·증시·코인 답에는 최근 14 거래일 차트가 사진으로 붙는다.
- 검색어는 자연어로 받는다. 약칭과 군더더기는 LLM이 풀지만, **종목이 실제로 있는지·좌표가 어디인지는 LLM이 정하지 않는다.** 시세 API·종목 색인·지오코딩이 확인한다.

## 빠른 시작

**필요한 것**: JDK 21, Docker. API 키는 없어도 앱은 뜬다(키가 빈 출처만 실패한다).

```bash
docker compose up -d redis                       # 1. Redis만 컨테이너로 띄운다
cp backend/.env.example backend/.env             # 2. 키를 채운다 — 키마다 「없으면 무엇이 안 되는지」 적혀 있다
cd backend && ./gradlew test                     # 3. 테스트 — 무엇을 고치든 이것부터
set -a; . ./.env; set +a; ./gradlew bootRun      # 4. 실행 — .env를 환경변수로 넘긴다 (앱은 파일을 직접 읽지 않는다)
```

포트는 두 개다 — `8080` 텔레그램 웹훅, `8081` 관리용(액추에이터). 배포와 웹훅 등록은 [docs/runbook.md](docs/runbook.md).

## 기술 스택

- Spring Boot 4 · JDK 21 (가상 스레드)
- Redis — 캐시 · 락 · 발송 기록 · 토큰 · 쿼터
- Docker 이미지(GHCR) · Render · GitHub Actions
- `backend/`는 헥사고날 구조이고, 패키지 경계는 ArchUnit 테스트가 지킨다
- 아직 없는 것: 프론트엔드(Vue) · 애드센스 · k8s
