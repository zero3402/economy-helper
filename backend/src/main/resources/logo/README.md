# 아이콘

시세 답에 붙이는 아이콘. `LogoCatalog`가 `{티커 소문자}.png`로 찾고, 없으면 `generic.png`를 쓴다.

## 출처와 라이선스

[spothq/cryptocurrency-icons](https://github.com/spothq/cryptocurrency-icons) —
**CC0 1.0 Universal (퍼블릭 도메인)**. 저작권 표시 의무가 없고 상표를 주장하지 않는 재도안
아이콘이다. 128×128 컬러 판을 그대로 가져왔다.

## 왜 열 개뿐인가

업비트 원화 마켓만 283개고 상장이 계속 바뀐다. 전부 채우면 손으로 쫓아다녀야 하는 목록이
하나 더 생긴다. 시총 상위 열 개가 조회의 대부분이고, 나머지는 `generic.png`로 충분하다 —
아이콘은 정보가 아니라 시선의 표식이다.

## 왜 주식·지수 로고가 없는가

기업 로고는 상표라 저장소에 담을 수 없다. 상표권 없는 대체물을 억지로 만들면 그건 그 회사가
아니게 되므로 아예 두지 않고 `generic.png`로 보낸다.

## 추가하려면

파일 하나를 이 디렉터리에 `{티커 소문자}.png`로 넣으면 끝이다. 코드는 고칠 것이 없다.
같은 이름으로 덮어쓰면 교체된다.
