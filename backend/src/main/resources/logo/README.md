# 아이콘

시세 답에 붙이는 아이콘. `LogoCatalog`가 `{티커 소문자}.png`로 찾고, 없으면 `generic.png`를 쓴다.

## 두 갈래

| 갈래 | 개수 | 출처 |
|---|---|---|
| 코인 (`btc.png` 등) + `generic.png` | 11 | [spothq/cryptocurrency-icons](https://github.com/spothq/cryptocurrency-icons) — **CC0 1.0 (퍼블릭 도메인)**. 저작권 표시 의무가 없고 상표를 주장하지 않는 재도안 아이콘이다. 128×128 컬러 판을 그대로 가져왔다 |
| 주식·지수 (`005930.png`·`nvda.png`·`kospi.png` 등) | 25 | `backend/tools/LogoTiles.java`가 그린 타일 |

## 왜 주식은 로고가 아니라 타일인가

기업 로고는 **상표**다. 화면에 띄워 "이 회사 주가"를 가리키는 것과, 파일을 저장소에 넣어
배포하는 것은 다른 행위다. 코인처럼 CC0로 배포되는 기업 로고 세트는 없고, 위키미디어의
`PD-textlogo`도 **저작권만** 소멸했을 뿐 상표는 그대로다.

그래서 **글자만** 넣은 타일을 직접 그렸다. 도형·심벌을 흉내 내지 않는다 — 흉내 내는 순간
"그 회사 로고 비슷한 것"이 되어 애초에 피하려던 문제로 돌아간다. 배경색은 키에서 유도하므로
같은 종목은 언제나 같은 색이고, 종목을 더해도 기존 색이 흔들리지 않는다.

## 왜 갈래마다 열 개뿐인가

업비트 원화 마켓만 283개, 코스피·코스닥은 2,700개가 넘고 상장이 계속 바뀐다. 전부 채우면
손으로 쫓아다녀야 하는 목록이 하나 더 생긴다. 시총 상위 열 개가 조회의 대부분이고, 나머지는
`generic.png`로 충분하다 — 아이콘은 정보가 아니라 시선의 표식이다.

## 추가하려면

- **코인**: CC0 아이콘을 `{티커 소문자}.png`로 넣으면 끝이다.
- **주식·지수**: `tools/LogoTiles.java`의 목록에 한 줄 넣고 `cd backend/tools && java LogoTiles.java`.

어느 쪽이든 코드는 고칠 것이 없다. 같은 이름으로 덮어쓰면 교체된다.
국내 지수처럼 파일명으로 쓸 수 없는 이름은 `LogoCatalog.ALIASES`가 옮긴다.
