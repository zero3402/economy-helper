# news

아침 브리핑 뉴스(코인 5 + 경제 5)와 `/news`(`/n`) — RSS 수집, 점수, 한글 번역.

## 검증

- `cd backend && ./gradlew test --tests 'io.saiden.economyhelper.news.*'`
- 피드 URL을 바꾸면 `--tests '*EconomyHelperPropertiesTest'`도 돌린다.

## 규칙

- 브리핑은 무리(`NewsCategory`)마다 다섯 자리씩 채우고, 모자란 무리를 다른 무리로 메우지 않는다 → ADR-0015
- 화면은 점수순으로 섞고 무리 제목을 달지 않는다. 검색 답은 무리로 가르지 않는다 → ADR-0016
- `/news`만 검색어 없이 답한다(`Command`의 인자 세 상태) → ADR-0016
- 번역은 요약하지 않는다 → ADR-0015
- 페이월 매체를 쓰지 않는다. 그 매체 피드에서는 그 매체 기사만 쓴다(`NewsSource.owns`) → ADR-0014
- 피드 URL 끝에 슬래시를 붙이지 않는다 → ADR-0014
- 코인 판정은 피드 기준 → 낱말 기준 두 규칙뿐이다. LLM에게 묻지 않고 캐시에 담지 않는다. 짧은 티커를 낱말 목록에 넣지 않는다 → ADR-0015
- 기사 페이지의 봇 검문을 우회하지 않는다(우리는 피드만 받는다) → ADR-0014
- 수집량이 이상하면 기준선과 견준다 → ADR-0014
- 검색어의 ASCII 낱말은 단어 경계로 맞추고 `&`·`.`을 지킨다. 조사는 3글자 이상 남을 때만 뗀다. 번역할 낱말은 5개까지 → ADR-0016
- LLM이 막혔을 때의 대체값(전부 통과 관련도·원문 번역)은 캐시하지 않는다 → ADR-0015
