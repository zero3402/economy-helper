# weather

날씨 — 오전 8시 알람(네 지역)과 `/weather` 검색(전 세계, 일일 예보). 출처는 기상청(국내) → AccuWeather → Open-Meteo.

## 검증

- `cd backend && ./gradlew test --tests 'io.saiden.economyhelper.weather.*'`
- 알람과 검색은 글자까지 같아야 한다 — `WeatherDigestJobTest.rendersExactlyLikeSearch` → ADR-0013

## 규칙

- 하루는 오전 한 줄·오후 한 줄이고 두 줄은 늘 나온다. 반나절마다 가장 센 토막 하나 → ADR-0011
- ☔ 줄의 이름은 강수 코드에서만 고른다. 「안 온다」는 코드와 양이 함께 말해야 하고 `null`은 `0`이 아니다 → ADR-0011
- 한 블록의 강수 확률과 시각은 한 예보에서 나온다. 지나간 날은 건드리지 않는다 → ADR-0011
- 한 답은 한 출처가 낸다. 출처마다 맡는 기간이 다르다(`supports()`) → ADR-0009
- 알람 좌표는 설정에 박는다 — 지오코딩·LLM을 타지 않는다 → ADR-0013
- 지오코딩 후보에 인구가 없으면 빈손을 준다 → ADR-0012
- 날짜는 조회한 지역의 현지 달력으로 자르고, 캐시 키는 기호를 지킨다. 「주말」은 요일, 요일은 그날 하루 → ADR-0012
- 기상청 키를 다시 인코딩하지 않는다. 에러는 HTTP 200의 다른 봉투로 온다. +3일까지만 맡는다 → ADR-0010
- 기상청 오늘 오전과 일 최저·최고는 02시 발표에서 메우고, 못 메우면 그 날을 버린다 → ADR-0010
- 기상청 어휘는 강수가 하늘을 이기고, `강수없음`은 `0`이다 → ADR-0010
- AccuWeather는 `details=true`를 빼지 않는다 → ADR-0009
