# weather

날씨 — 오전 8시 알람(네 지역)과 `/weather` 검색(전 세계, 일일 예보).
출처 순서: 기상청(국내) → AccuWeather → Open-Meteo.

## 검증

- `cd backend && ./gradlew test --tests 'io.saiden.economyhelper.weather.*'`
- 알람과 검색 결과는 글자까지 같아야 한다 — `WeatherDigestJobTest.rendersExactlyLikeSearch` → ADR-0013

## 규칙

**출처**

- 한 답은 한 출처가 낸다. 출처마다 맡는 기간이 다르다(`supports()`) → ADR-0009
- AccuWeather 호출에서 `details=true`를 빼지 않는다 → ADR-0009
- 시간별 강수 보충은 브레이커·재시도 이름을 예보와 나눠 둔다. 합치면 보충의 실패가 2순위 폴백까지 막는다 → ADR-0009
- 기상청 키를 다시 인코딩하지 않는다. 에러는 HTTP 200에 다른 JSON 모양으로 온다. 기상청은 3일 뒤까지만 맡는다 → ADR-0010
- 기상청의 오늘 오전과 하루 최저·최고는 02시 발표로 채우고, 못 채우면 그 날을 버린다 → ADR-0010
- 기상청 날씨 표현은 강수가 하늘 상태보다 우선이고, `강수없음`은 `0`이다 → ADR-0010

**검색 해석**

- 지오코딩 후보에 인구 정보가 없으면 「결과 없음」으로 답한다 → ADR-0012
- 날짜는 조회한 지역의 현지 달력으로 자르고, 캐시 키에서 기호를 지우지 않는다. 「주말」은 토·일, 요일은 그날 하루 → ADR-0012
- 알람 좌표는 설정에 고정한다 — 지오코딩·LLM을 거치지 않는다 → ADR-0013

**화면**

- 하루는 오전 한 줄·오후 한 줄이고, 두 줄은 항상 나온다. 반나절마다 가장 센 구간 하나만 적는다 → ADR-0011
- ☔ 줄의 날씨 이름은 강수 코드에서만 고른다. 「안 온다」는 코드와 강수량이 함께 말해야 하고, `null`은 `0`이 아니다 → ADR-0011
- 한 블록의 강수 확률과 시각은 한 예보에서 나온다. 지나간 날은 건드리지 않는다 → ADR-0011
