# stock

`/stock`(`/s`) — 국내·미국 종목·지수·국내 ETF의 시세와 전망(목표주가·실적발표일·배당).
1순위는 KIS, 2순위는 국내 공공데이터포털 · 미국 FMP.

## 검증

- `cd backend && ./gradlew test --tests 'io.saiden.economyhelper.stock.*'`

## 규칙

**종목 찾기**

- 국내 ETF·종목은 KIS 종목 마스터 색인(`StockListings`)이 확정한다. 코드와 이름이 서로 다른 종목을 가리키면 이름을 믿는다 → ADR-0003
- 화면에 쓰는 이름은 프롬프트가 아니라 `StockService.displayName`이 정한다 → ADR-0003
- 미국 거래소는 NAS → NYS → AMS 순으로 찾는다(기억한 거래소가 있으면 그것부터, 비면 나머지도). 프롬프트로 시장을 좁히지 않고, 셋 다 비면 `Unsupported`를 던진다 → ADR-0001
- 클래스 주식 표기(`BRK.B`↔`BRK/B`)는 `ClassShare` 한 곳에서 판정한다 → ADR-0001

**시세**

- KIS 응답의 `0`과 빈 배열은 값이 아니다. 지수 표와 브리핑 목록을 한 설정으로 합치지 않는다 → ADR-0001
- 출처가 전부 실패하면 「못 찾음」이 아니라 「잠시 후 다시」다. 장이 닫힌 날의 KIS 값은 (종가)로 표시한다 → ADR-0001
- KIS 토큰·호출 간격은 `infrastructure/kis/AGENTS.md`를 따른다.

**전망 (목표주가·실적발표일·배당)**

- 없는 값은 줄을 적지 않는다. 전망 조회가 실패해도 시세는 나간다 → ADR-0006
- 지수에는 전망을 붙이지 않는다. ETF는 목표주가·실적발표일만 빼고 배당은 붙인다 → ADR-0006
- 달러 목표가의 원화 환산은 시세 줄과 같은 환율로 한다(브리핑은 환율을 한 번만 조회해 끝까지 쓴다) → ADR-0006
- 국내 목표가는 증권사별 최신 하나씩으로 평균하고 `0`은 뺀다. 미국은 `targetConsensus`를 쓴다 → ADR-0004
- 실적발표일은 첫 행을 그냥 집지 않는다. 미국 달력 기준 오늘 이후 가장 이른 날짜를 고른다 → ADR-0004
- 투자의견 등급을 다시 넣지 않는다 → ADR-0001
- FMP 전망은 하나라도 받으면 캐시에 담고, 전부 402·403이면 빈 값을 담는다. 다시 될 수도 있는 실패만 예외로 던진다 → ADR-0004
- 미국 배당은 Polygon(`MASSIVE_API_KEY`), 목표가·실적발표일은 FMP다. FMP는 심볼별 허용목록이라 402가 흔하다 → ADR-0005 · ADR-0004

**배당**

- 배당락일이 아니라 배당기준일을 적는다. `ex_dividend_date`로 대신하지 않는다 → ADR-0005
- 다음 배당은 `StockOutlook.Dividend.nextOf` 한 곳에서, 한 사건의 세 줄(기준일·지급일·금액)로 고른다. 앞으로 올 것이 없으면 「지난」 라벨을 붙여 보여 준다 → ADR-0005
- 빈 답은 `Dividend.none()`처럼 빈 값 객체로 담는다 — `null`은 스프링 캐시가 거절한다 → ADR-0005
- 예탁원 배당 응답은 `output1` 배열이고, 필드마다 날짜 형식이 다르며, 미정은 `"0"`·`""`다. 조회 범위는 400일(투자의견의 180일과 상수를 따로 둔다) → ADR-0005
- 「오늘」은 그 시장의 달력으로 자른다. 전망 캐시는 그 시장의 자정을 넘기지 않는다(`UntilMidnightTtl`) → ADR-0005 · ADR-0004

**차트**

- 미국 종목 일봉은 종목 전용 경로에 `MODP=0`. 국내 일봉은 시세 호출의 `output2`로 캐시를 미리 채운다(키는 `@Cacheable` 키와 글자까지 같게) → ADR-0007
