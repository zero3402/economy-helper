# crypto

`/crypto` — 업비트(원화)와 바이낸스(USDT) 시세를 나란히 보여 주고 김치 프리미엄을 계산한다.

## 검증

- `cd backend && ./gradlew test --tests 'io.saiden.economyhelper.crypto.*'`

## 규칙

- 코인 이름은 업비트 목록에서 찾는다. 후보가 여럿이면 24시간 거래대금 1위를 고른다. 업비트에 없는 코인만 LLM에게 묻는다 → ADR-0008
- 바이낸스 에러는 코드별로 다르게 처리한다: 400(`-1121`)은 그 코인만 「미상장」, 418·429는 호출을 멈추고 브레이커를 연다, 451만 미러 주소로 한 번 더 묻는다 → ADR-0008
- 418(IP 밴)일 때는 미러를 부르지 않는다 — 밴이 길어지고, 두 주소가 같은 IP 한도를 나눠 쓴다 → ADR-0008
- 코인 일봉 차트는 업비트 캔들만 쓴다(바이낸스 klines는 쓰지 않는다) → ADR-0007
- 짧은 영문 검색어는 심볼이 정확히 같을 때만 맞춘다. 업비트 시세 호출이 실패하면 LLM으로 넘기지 않는다 → ADR-0008
