# crypto

`/crypto` — 업비트·바이낸스 시세를 나란히 적고 김치 프리미엄을 낸다.

## 검증

- `cd backend && ./gradlew test --tests 'io.saiden.economyhelper.crypto.*'`

## 규칙

- 이름은 업비트 목록으로 맞추고, 후보가 여럿이면 24시간 거래대금 1위. 업비트에 없는 코인만 LLM에게 묻는다 → ADR-0008
- 바이낸스 400(`-1121`)은 그 코인만 미상장, 418·429는 물러서 브레이커를 연다, 451만 미러로 한 번 더 → ADR-0008
- 418에는 미러를 부르지 않는다 — 밴을 연장하고 두 호스트가 IP 예산을 나눈다 → ADR-0008
- 코인 일봉은 업비트 캔들만 쓴다(바이낸스 klines는 쓰지 않는다) → ADR-0007
- 짧은 영문은 심볼 정확 일치만 본다. 업비트 시세 호출이 실패하면 LLM으로 넘기지 않는다 → ADR-0008
