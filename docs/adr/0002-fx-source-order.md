# ADR-0002 — 환율 출처 순서

> **한 줄 요약**: 원/달러 환율은 KIS → 유럽중앙은행 → 수출입은행 순으로 묻고, 첫 성공에서 멈춘다.

| 상태 | 범위 |
|---|---|
| 채택 | `fx/**` |

## 맥락

`/fx`와 브리핑의 원/달러 환율. 세 출처의 성격이 다르다.

| 출처 | 값이 바뀌는 때 | 한도 |
|---|---|---|
| KIS | 하루 중에도 계속 | KIS 공통 한도 |
| 유럽중앙은행(Frankfurter) | 영업일 16시 CET에 한 번 고시 | 없음 (키도 없음) |
| 수출입은행 | 하루 한 번 고시 | 하루 1,000회 |

## 결정

| 순위 | 출처 | 화면 표시 |
|---|---|---|
| 1 | 한국투자증권 | 시각까지(`FxSource.intraday`). 장이 닫힌 날은 마지막 영업일 날짜 + (종가) |
| 2 | 유럽중앙은행 | 날짜 + (고시) |
| 3 | 수출입은행 | 날짜 + (고시) |

- **유럽중앙은행이 수출입은행보다 앞이다.** 브리핑 시각(오전 9시)에 받을 수 있는 가장 최근 값이 유럽중앙은행은 어제 23시(KST), 수출입은행은 어제 11시라 유럽중앙은행이 더 최신이다. 키도 한도도 없어서 받쳐 주는 자리에 맞다.
- **셋을 다 불러서 가장 최신 값을 고르지 않는다.** 그건 이중화가 아니라 선택이고, 요청마다 수출입은행 한도를 쓴다.

## 결과

- 순서를 바꿔도 실시간이 되지는 않는다. 유럽중앙은행은 하루에 한 번만 낸다.
- 예비 출처로 넘어가면 화면에 출처와 날짜가 표시된다([design.md 4.7](../design.md#47-값의-성격을-화면까지-나른다)).

## 근거

- 고시 시각: 유럽중앙은행 16:00 CET(KST 23:00 또는 24:00), 수출입은행 오전 11시경. 브리핑은 오전 9시에 나간다.
- 수출입은행 Open API는 하루 1,000회 한도.
