# ADR-0002 — 환율 출처 순서: KIS → 유럽중앙은행 → 수출입은행

- **상태**: 채택
- **범위**: `fx/**`

## 맥락

`/fx`와 브리핑의 원/달러 환율. 출처 셋의 성격이 다르다 — KIS는 하루 중에도 움직이고, 유럽중앙은행(Frankfurter)은 영업일
16시 CET에 한 번, 수출입은행은 하루 한 번 고시한다. 수출입은행은 하루 1,000회 한도가 있다.

## 결정

| 순위 | 출처 | 화면 표기 |
|---|---|---|
| 1 | 한국투자증권 | 시각까지(`FxSource.intraday`). 장이 닫힌 날은 마지막 영업일 날짜 + (종가) |
| 2 | 유럽중앙은행 | 날짜 + (고시) |
| 3 | 수출입은행 | 날짜 + (고시) |

- **유럽중앙은행이 수출입은행보다 앞이다** — 브리핑 시각(오전 9시)에 받을 수 있는 가장 최근 값이 어제 23시(KST)로, 수출입은행의
  어제 11시 고시보다 신선하다. 키도 한도도 없어 받쳐 주는 자리에 맞다.
- **셋을 다 불러 가장 신선한 것을 고르지 않는다** — 그건 선택이고 요청마다 수출입은행 한도를 태운다.

## 결과

- 순서를 바꾼다고 실시간이 되지 않는다 — 유럽중앙은행은 하루 한 번 낸다.
- 폴백이 일어나면 화면이 출처와 날짜로 밝힌다([design.md 4.7](../design.md#47-값의-성격을-화면까지-나른다)).

## 근거

- 고시 시각: 유럽중앙은행 16:00 CET(KST 23:00 또는 24:00), 수출입은행 오전 11시경. 브리핑은 오전 9시에 나간다.
- 수출입은행 Open API 일 1,000회 한도.
