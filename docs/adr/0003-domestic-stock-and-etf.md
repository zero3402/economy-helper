# ADR-0003 — 국내 종목·ETF 해석: KIS 종목 마스터 색인과 공공데이터포털 2순위

- **상태**: 채택
- **범위**: `stock/**`

## 맥락

`/stock`은 약칭·자연어(`삼전`, `타임나스닥100`, `제피`)를 받는다. KIS에는 종목명 검색이 없고(코드 → 이름 방향뿐),
공공데이터포털 주식시세정보는 이름 검색이 되지만 **주식만** 준다. 국내 ETF는 별도 API(증권상품시세정보)이고 활용신청도 따로다.

## 결정

1. **이름 → 종목코드 색인은 KIS 종목 마스터 파일**(`kospi_code.mst.zip`·`kosdaq_code.mst.zip`, `KisMasterClient` → `StockListings`)이다.
   키가 없고 6시간 캐시(`kr-listings`)에 프로세스 사본을 6시간 든다. **6자 단축코드만** 남긴다(KIS 국내 시세가 받는 모양).
2. **색인 규칙**: 정규화한 이름이 정확히 같은 상장, 아니면 질의를 숫자·영문·한글 토큰으로 쪼개 **토큰 전부를 품는** 상장 중
   **시가총액 1위**. 한 글자 같은 너무 짧은 부분일치는 쓰지 않는다. 지수 이름(`digest.indices`)은 부분일치보다 먼저 정확히 맞춘다.
3. **LLM(`StockResolver`)은 상장명을 소리 맞춰 내고 코드는 색인이 확정한다.** 국내 ETF는 「code를 확실할 때만, name에 KRX
   상장명 — 브랜드는 영문 그대로(타임 → TIME)」. 한글로 적은 미국 티커(`제피 → JEPI`)도 LLM이 소리로 맞춘다 — 표를 두지 않는다.
4. **코드와 이름이 서로 다른 종목을 가리키면 이름을 믿는다**(`StockListings.sameListing`) — 단, 이름이 **딱 맞는** 상장이
   있을 때만이다(`삼성전자우` ⊃ `삼성전자`처럼 더 긴 이웃이 토큰을 다 품는다). 이름으로 못 찾으면 코드를 쓴다(`네이버` → `NAVER`).
5. **화면 이름은 코드가 정한다**(`StockService.displayName`) — 한글이 없으면 티커로 적는다.
6. **2순위는 공공데이터포털**(전일 종가): 주식은 `StockPriceApi`, ETF는 `EtfPriceApi`(`getETFPriceInfo`). 코드 조회는 응답의
   `srtnCd`가 **정확히 같은 행만** 받는다. 이름 검색은 API별로 최신 기준일을 고르고, 주식·ETF 후보를 합쳐 시총 1위를 고른다.
   **브레이커는 주식(`dataGo`)과 ETF(`dataGoEtf`)가 따로**다.
7. **LLM이 지수로 잘못 분류해도** 국내 이름 검색으로 한 번 더 찾는다. 마스터 갱신이 실패하면 **옛 색인을 유지**한다.
8. 색인이 ETF·ETN이라고 알면 목표주가를 묻지 않는다(배당은 묻는다) — ETF의 `invest-opinion`은 0행이다.

## 결과

- 이름으로 찾은 국내 종목에도 코드가 생겨 1순위 실시간·전망·차트가 붙는다.
- LLM 없이 `타임나스닥100`은 빈손이다(`타임`≠`time`).
- `kr-listings`를 비워도 프로세스 사본은 수명이 지나야 다시 읽는다.
- 이름 검색은 호출이 둘이다(주식·ETF, 하루 1만 회·1시간 캐시).

## 근거 (실측)

- **2026-08-28**: 공공데이터포털 주식시세정보 `likeItmsNm=KODEX`/`나스닥100`/`TIME` → 0건(`삼성전자`는 2건). 증권상품시세정보는
  신청 전 403 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`(같은 `DATA_API_KEY`, 활용신청 2026-08-28 승인).
- **마스터 형식**: 두 파일 220KB에 ETF 1,164건. **공식 파이썬 예제의 꼬리 길이(228/222)와 한 글자 다르다** — KOSPI 227 ·
  KOSDAQ 221, `꼬리[0:2]`가 그룹코드(`EF`가 ETF), `꼬리[-15:-6]`이 시가총액(억). 영숫자 6자 `0019K0`도 KIS가 받는다.
  Redis 값이 292KB·4천 행이라 조회마다 풀면 `/stock` 한 번에 네 번 했다 → 프로세스 사본.
- **LLM** (`gemini-flash-lite-latest`): 2026-08-26 한글 미국 티커 아홉 개, 2026-08-28 국내 ETF 상장명 열 개가 다 맞았다.
  「name은 사용자가 부른 이름으로」를 프롬프트에 넣자 `삼전`과 `나스닥`이 빈손이 됐다 — 문단 하나가 다른 판단을 흔든다.
- **`getETFPriceInfo`**: `srtnCd=426030`을 줘도 1,164건 전부가 온다(`srtnCd`는 무시된다) → `likeSrtnCd` + 응답 거르기.
  필드 이름이 주식과 같고 `fltRt`가 `-.14` 꼴로 온다.
- **LLM이 존재하는 틀린 코드**(KODEX의 코드에 TIME의 이름)를 주면 KIS가 멀쩡히 답해 다른 ETF가 나갔다 → 4번 결정.
- 공공데이터포털이 코드 부분일치로 다른 종목을 주던 것(`5930`)과 주식·ETF 기준일을 섞어 「삼성」이 ETF가 되던 것을
  2026-10-03에 고쳤다.
