# ADR-0015 — 뉴스 순위와 카테고리

> **한 줄 요약**: 조회수 순위는 공개되지 않으니 공개된 신호 네 개로 인기도를 추정한다. 브리핑은 코인·경제 카테고리마다 5건씩 채우고, 모자라도 다른 카테고리로 메우지 않는다.

| 상태 | 범위 |
|---|---|
| 채택 | `news/**` · `digest/**` · `translate/**` · `infrastructure/llm/**` · `telegram/**` |

## 맥락

아침 브리핑은 뉴스 10건(코인 5 + 경제 5)을 한글로 번역해 보낸다.

- 「조회수·댓글 순위」는 어느 매체도 공개하지 않는다.
- 코인 기사는 일반 금융 기사와 점수 경쟁을 하면 통째로 밀린다.

## 결정

### 순위

1. **인기도는 공개 신호 네 개로 추정한다**(`PopularityScorer`, 가중치는 설정 파일).

   | 신호 | 가중치 | 설명 |
   |---|---|---|
   | 피드 순위 | 35% | 매체가 피드 위쪽에 둔 기사 |
   | 신선도 | 25% | 최근 기사 |
   | 관련도 | 25% | LLM이 매긴 재테크 관련도. 상위 8건에만 매긴다 |
   | HN 반응 | 15% | Hacker News 반응. 넷 중 유일하게 실제로 측정된 다른 사람들의 반응이다 |

2. **번역은 요약하지 않는다.** 프롬프트에 「요약하거나 줄이지 말고 원문의 내용을 그대로 옮기세요」라고 못 박는다.
   Gemini가 막혀 원문 그대로 나간 결과와 「전부 통과」 관련도는 캐시하지 않는다.

### 카테고리 (`NewsCategory`)

3. **판정 규칙은 둘뿐이다.**
   - 코인 전용 피드에서 왔으면(`NewsSource.cryptoSection()`) → 코인
   - 아니면 제목·요약에 **코인 단어가 있으면** → 코인, 없으면 → 경제
4. **LLM에게 묻지 않고, 캐시에 담지 않고, 읽을 때 계산한다.** 그래서 단어 목록을 고치면 이미 캐시된 기사까지 바로 바뀐다.
5. **짧은 티커는 단어 목록에 넣지 않는다.** `defi` → `deficit`, `eth` → `whether`, `sol` → `solution`처럼 다른 단어에 걸린다. `ripple`과 그냥 `coin`도 뺐다.

### 자리 배분

6. **브리핑은 카테고리마다 5건씩 채운다.** **모자란 카테고리를 다른 카테고리 기사로 메우지 않는다.** 코인 기사가 3건뿐인 날은 8건만 나간다. 못 채운 자리는 로그로 남긴다.
7. **화면에는 카테고리 제목이 없다.** 메시지 제목은 `뉴스 1/10` … `뉴스 10/10`이고 점수순으로 섞여 나간다. 배분이 정하는 것은 「어떤 10건이 들어가는가」이지 순서가 아니다.
8. **기사 하나에 메시지 하나다.** 링크 미리보기 카드가 메시지 맨 아래에 하나만 붙기 때문이다. 브리핑 뉴스 한 통이 거절돼도 다음 기사는 보낸다.

## 결과

- 코인 매체가 쓴 일반 기사도 코인으로 분류된다. 반대 방향(코인 기사가 경제로 새는 것)이 더 나쁘다.
- 뉴스만 10통이라, 같은 방에 1초에 한 통씩 보내면 브리핑 24통이 약 25초 걸린다. 발송 시간대가 두 시간이라 문제없다.

## 근거

- 매체의 「Most Read」 페이지도 전부 403/404였다.
- CoinDesk의 「Nvidia shares rise after earnings top estimates」가 코인으로 분류됐다(받아들인 대가).
- 카테고리 구분 없이 전체 상위 N건을 뽑던 때는 코인 뉴스가 하나도 안 나가는 날이 있었다.
