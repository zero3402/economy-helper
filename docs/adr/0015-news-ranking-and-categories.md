# ADR-0015 — 뉴스 순위와 무리: 공개 신호로 근사하고, 무리마다 다섯 자리

- **상태**: 채택
- **범위**: `news/**` · `digest/**`

## 맥락

아침 브리핑은 뉴스 열 건(코인 5 + 경제 5)을 한글로 옮겨 보낸다. 「조회수·댓글 순위」는 어느 매체도 공개하지 않는다. 코인 기사는
금융 일반 피드에서 점수 경쟁에 통째로 밀린다.

## 결정

**순위**

1. **인기도는 공개 신호 넷으로 근사한다**(`PopularityScorer`) — 피드 순위 .35 · 신선도 .25 · 관련도 .25 · HN 반응 .15(가중치는 설정).
   그중 HN 반응만이 실측된 남의 반응이다. LLM 관련도는 상위 8건에만 태운다.
2. **번역은 요약하지 않는다** — 프롬프트가 「요약하거나 줄이지 말고 원문의 내용을 그대로 옮기세요」라고 못 박는다.
   Gemini가 막혀 원문으로 강등된 결과와 「전부 통과」 관련도는 캐시하지 않는다.

**무리**(`NewsCategory`)

3. **코인만 싣는 피드에서 왔으면 코인이다**(`NewsSource.cryptoSection()`). 아니면 **제목·요약문에 코인 낱말이 있으면** 코인, 그 밖은 경제.
4. **LLM에게 묻지 않고, 캐시에 담지 않고 읽을 때 계산한다** — 낱말 목록을 고치면 옛 항목까지 낫는다.
5. **짧은 티커를 낱말 목록에 넣지 않는다**(`defi`→`deficit`, `eth`→`whether`, `sol`→`solution`). `ripple`·맨 `coin`도 뺐다.

**할당**

6. **브리핑은 무리마다 다섯 자리씩 채운다.** **모자란 무리는 다른 무리로 메우지 않는다** — 코인이 세 건뿐인 날은 여덟 건이 나간다.
   못 채운 자리는 로그로 남긴다.
7. **화면에 무리 제목은 없다** — 통 제목은 `뉴스 1/10` … `뉴스 10/10`이고 점수순으로 섞여 나간다. 할당량이 정하는 것은 어느 열 건이
   들어오는가이지 순서가 아니다.
8. **기사마다 한 통이다** — 미리보기 카드가 통 맨 아래에 하나만 붙는다. 브리핑 뉴스 한 통이 거절돼도 뒤의 기사는 보낸다.

## 결과

- 코인 매체가 낸 일반 기사는 코인 무리로 간다 — 코인 기사가 경제로 새는 반대 방향이 더 나쁘다.
- 뉴스만 열 통이라 같은 방 초당 한 통 간격으로 브리핑 스물네 통이 ~25초다. 발송 창이 두 시간이라 문제가 아니다.

## 근거

- Most Read 페이지도 전부 403/404였다.
- CoinDesk의 「Nvidia shares rise after earnings top estimates」가 코인 무리로 갔다(받아들인 대가).
- 통틀어 상위 N건이던 동안 코인 뉴스가 하루도 안 나가는 날이 있었다.
