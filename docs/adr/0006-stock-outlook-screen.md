# ADR-0006 — `/stock` 전망 화면

> **한 줄 요약**: 시세 아래에 목표주가·실적발표일·배당을 블록으로 붙인다. 없는 값은 줄이 아예 없고, 전망이 실패해도 시세는 나간다.

| 상태 | 범위 |
|---|---|
| 채택 | `telegram/presentation/**` · `stock/domain/**` |

## 맥락

`/stock` 답과 브리핑의 증시 메시지는 시세 아래에 **목표주가 · 실적발표일 · 배당**을 함께 적는다. 시장마다 채울 수 있는 칸이 다르다.

| 값 | 국내 | 미국 |
|---|---|---|
| 목표주가 | KIS `invest-opinion` | FMP `price-target-consensus` |
| 실적발표일 | **없음** — 무료 출처가 없다 | FMP `/stable/earnings` |
| 배당기준일·배당지급일·배당금 | KIS `ksdinfo/dividend`(예탁원) | Polygon `v3/reference/dividends` |

## 결정

화면은 이렇게 생겼다.

```
삼성전자                 애플
239,500 KRW             232.14 USD
🔵 -1.26%               327,821 KRW
                        🔵 -1.75%
목표가                   목표가
466,667 KRW             340.72 USD
                        481,155 KRW

                        실적발표일(미국)
                        2026.10.29(목)

배당지급일               배당기준일(미국)
2026.11.19(목)          2026.11.10(화)
```

| 규칙 | 이유·설명 |
|---|---|
| **블록은 각각 따로 나온다** | 배당은 세 줄이라 블록은 최대 다섯 개. **없는 값은 줄이 아예 없다** |
| **라벨이 블록의 머리다** | 라벨 앞에 빈 줄을 둔다. 빈 줄은 블록 사이, 줄바꿈 하나는 블록 안 |
| **지수에는 붙이지 않는다. ETF는 목표주가·실적발표일만 뺀다** | 목표주가·실적발표일은 기업에 대해 내는 값이다. 배당은 ETF에도 있다 |
| **부가 정보다** | 전망이 실패해도 시세는 그대로 나간다 |
| **목표가도 시세와 같은 환율로 원화 환산한다** | 한 메시지에 환율 두 개가 섞이면 어느 쪽도 못 믿는다. 브리핑은 환율을 한 번 조회해 증시 메시지까지 들고 간다. 환율을 못 구하면 환산 줄만 빠진다 |
| **기준 꼬리표는 라벨에 붙인다** — `실적발표일(미국)` · `배당기준일(미국)` | 날짜가 미국 거래일 그대로라서다. `(현지)`는 어디인지 말해 주지 않고, `(미국 현지)`는 너무 길다. 괄호 앞 공백은 없다. 환율의 `(고시)`, 증시의 `(종가)`, 날씨의 `(예보)`와 같은 자리다 |
| **날짜는 `MessageLayout.DATE` 형식 하나** (`2026.10.29(목)`) | 연도가 있어야 다음 분기인지 내년인지 알 수 있다 |

## 결과

- 종목 하나가 최대 17줄이다. 메시지 한도 4,096자에 한참 못 미친다.
- 화면은 길어지지만, 「이 값이 언제 것이고 어디서 왔나」를 따로 물을 필요가 없다.

## 근거

- 지수 넷·종목 셋에 전망을 모두 붙인 브리핑 증시 메시지가 실측 673자·89줄이었다.
- 미국 실적 발표는 장 마감 뒤라 KST로 옮기면 대개 다음 날 새벽이 된다. 그래서 「그 시장의 달력」으로 적는다.
