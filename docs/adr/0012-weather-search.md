# ADR-0012 — 날씨 검색 해석

> **한 줄 요약**: LLM은 지명과 「며칠 뒤」 같은 기간을 말로만 돌려주고, 실제 날짜는 코드가, 좌표는 지오코딩이 정한다. 좌표가 의심스러우면 「결과 없음」으로 답한다.

| 상태 | 범위 |
|---|---|
| 채택 | `weather/**` |

## 맥락

`/weather`는 `내일 서현` · `2025년 8월 19일 서현` · `일주일치 파리` · `다음 주 화요일 미금`처럼 지명과 기간을 말로 받는다.

- LLM(`WeatherResolver`)이 지명과 기간을 뽑는다.
- 실제로 있는 곳인지와 좌표는 Open-Meteo 지오코딩이 정한다.
- 그런데 지오코딩은 짧은 한국어 지명에 인구 정보가 없는 시골 마을만 돌려줄 때가 있다.

## 결정

### 기간

1. **LLM은 상대 표현을 날짜로 바꾸지 않는다.** 대신 아래 필드로 돌려주고, 날짜는 코드가 오늘 기준으로 계산한다.

   | 필드 | 뜻 |
   |---|---|
   | `offsetDays` | 며칠 뒤 |
   | `days` | 며칠치 |
   | `weekend` | 주말 |
   | `weekday` | 요일 (1=월 … 7=일) |
   | `weekOffset` | 몇 주 뒤 |
   | `month` / `day` | 직접 적은 날짜 |

   여러 개가 오면 **적은 날짜 > 요일 > 주말** 순으로 따른다.
2. **「주말」은 일수가 아니라 요일이다**(`WeatherPeriod.weekend`) — 다가오는 토·일. 「다음 주말」은 `offsetDays: 7`.
3. **요일은 그날 하루다**(`WeatherPeriod.weekday`).
   - 「일요일」 = 다가오는 일요일 (오늘이 일요일이면 오늘)
   - 「다음 주 월요일」 = 다음 주(월~일)의 월요일. `weekOffset`을 반영한다.
4. 받은 `month`가 1~12가 아니면 「날짜를 못 읽음」으로 답한다.
   **사용자가 직접 친 「N일 뒤·후」(`10일 뒤` · `사흘 후`)는 코드가 읽어서 LLM 답을 덮어쓴다**(`WeatherResolver.daysLaterAsTyped`). 입력에 그대로 있는 사실이라 LLM 해석에 맡기지 않는다.
5. **날짜는 조회한 지역의 현지 달력으로 자른다**(`timezone=auto`).
6. **LLM에는 사용자가 친 그대로 보여 주고, 캐시 키에서도 기호를 지우지 않는다**(`WeatherResolver.cacheKey` — 전각/반각·대소문자·공백만 통일한다).

### 지명

7. **LLM이 정식 행정명으로 바꾼다**(서울특별시 · 성남시 · 부산광역시). **인구 정보가 있는 후보가 하나도 없으면 「결과 없음」으로 답한다.** 틀린 좌표는 결과 없음보다 나쁘다.
8. 해외 지명은 한국어 통용명을 그대로 두고, 영문은 끝까지 적는다. 지오코딩 결과가 로마자로 오면 사용자가 물어본 한국어 지명으로 표시한다(`GeoLocation.labelledFor` — 읽을 때 정한다).
9. 프롬프트나 선택 규칙을 고치면 `weather-resolve` · `geocode` 캐시의 판 번호(버전)를 올린다([design.md 4.2](../design.md#42-캐시)).

## 결과

- 해석은 7일, 지오코딩은 30일 캐시라 잘못된 답 하나가 그 기간 내내 남을 수 있다. 판 번호 규칙이 그 방어다.

## 근거 (실측)

| 항목 | 관찰 |
|---|---|
| **지오코딩** (`language=ko`) | `서현` → 김포시, `성남` → 전라북도(분당에서 200km), `부산` → 경상북도, `서울` → 0건. `New York`은 네브래스카주 York(인구 7,864)로 잡힌다 |
| **캐시 키** (신고 2026-09-29) | 공백·기호를 지운 형태(`일주일치미금` · `816서울`)를 프롬프트에 넣던 때 「`/weather 일주일치 미금`이 이틀치」로 나왔다. 키가 `1/11 서울`과 `11/1 서울`을 한 칸으로 합치면 먼저 물은 날짜가 7일 동안 답한다 |
| **요일** (신고 2026-09-29) | 요일 필드가 없던 때 `일요일 미금`이 주말로 읽히거나 오늘 날씨가 나갔다. 실측(`gemini-flash-lite-latest`): `일요일`→7 · `토요일`→6 · `다음 주 월요일`→1 + 1주 · `이번 주 금요일`→5 |
| **옛 캐시** | `/weather 미금`을 고친 뒤에도 옛 해석(7일) · 옛 지오코딩(30일)이 남아 `Seongnam, 대한민국`(전라북도)을 답했다 → 결정 9 |
