## 새 ADR 쓰는 법

- **결정 하나에 파일 하나.** 번호는 다음 숫자를 쓴다(`0017-…`).
- 이미 있는 결정이 바뀌면 그 파일을 고친다. 결정이 뒤집혔으면 상태를 `대체됨(→ 00NN)`으로 바꾸고 새 파일을 쓴다. **지우지 않는다.**
- 형식: 맨 위에 **한 줄 요약**, 그다음 **상태 · 범위 · 맥락 · 결정 · 결과(대가) · 근거(실측)**.
- 실측은 **날짜와 파라미터까지** 적는다. 그날의 사실이므로 읽을 때 지금 코드와 맞춰 본다.
- 패키지 `AGENTS.md`의 규칙 줄은 `→ ADR-00NN`으로 이 문서들을 가리킨다.
